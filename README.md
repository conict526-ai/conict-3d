## 모바일 조작

화면 폭·높이와 터치 포인터를 함께 감지해 휴대폰, 가로 회전 화면, 터치 태블릿에 간결한 배치를 적용합니다. 왼쪽 조이스틱으로 이동하고 화면을 드래그해 시점을 바꿉니다. 조이스틱을 놓거나 앱을 벗어나면 이동 입력이 해제됩니다. 안내·투어·상세 패널은 접을 수 있고 메뉴와 지도는 필요할 때만 펼칩니다. 화면 아래 아이콘에는 접근성 이름과 선택 상태를 제공합니다.

공간 편집 스튜디오에서도 선택·속성, 평면도와 저장 메뉴를 개별적으로 접고 펼칠 수 있습니다. 작은 화면에서는 렌더 픽셀 비율을 1로 제한하고, 처음 읽는 아바타 텍스처는 최대 2048px로 GPU에 올립니다. 저장소의 원본 이미지·GLB 바이트는 유지합니다.

모바일 입력과 기존 이동 동작의 검사는 저장소 루트에서 다음과 같이 실행합니다.

```sh
node mobile-checks.mjs
node --experimental-loader ./test-loader.mjs checks.mjs
```

## 구성

- dist/: HTML, CSS, JavaScript와 정적 자산을 담은 사이트 원본이자 배포 폴더입니다. 별도 빌드 단계 없이 제공합니다.
- dist/assets/: 연구실·구성원 이미지, GLB 아바타, gzip 사본과 자산 설명·라이선스를 보존합니다.
- dist/vendor/: Three.js와 필요한 보조 모듈, 라이선스를 보존합니다.
- 개발기록.md: 이전 제작 기록, 기능 설명, 검사 방법입니다. 당시의 로컬 경로와 과거 배포 기록이 포함될 수 있습니다.
- serve.mjs: 로컬 개발용 서버입니다. 사용 방법과 선택적 PC 관찰 연동은 소스를 확인한 뒤 실행합니다.
- *-checks.mjs, checks.mjs, test-loader.mjs: 기존 기능의 검증 스크립트입니다.
- pack-rigs.mjs: GLB를 변경한 뒤 동일한 내용의 gzip 사본을 갱신합니다.

## 정적 사이트 실행

Python이 설치된 환경에서 저장소 루트에서 다음을 실행하고 http://localhost:8000 을 엽니다.

```sh
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

파일을 직접 더블클릭하는 file:// 방식은 ES 모듈과 자산 로딩에 적합하지 않습니다. 공간 편집 결과는 브라우저 로컬 저장소에 저장되므로 GitHub에 파일을 올리는 것만으로 여러 사용자의 편집 상태가 동기화되지는 않습니다.

GitHub Pages 등 정적 호스팅에는 dist/의 내용을 배포합니다. 모든 배포 파일의 상대 경로를 유지해야 합니다. 이 저장소는 별도 프로젝트이며 기존 개인 홈페이지 저장소와 연결하지 않습니다.

## 연구실 편지 화면 · 2026-10-25
